# Lab 1 — Foundations: Local and Cloud LLMs

**Time:** ~35 min

Local + cloud LLM calls, the reasoning dial, naive vs few-shot prompting. You'll talk to a local model running inside your Codespace and to OpenAI's API from the same Python code, and see what changes when you turn reasoning up and down.
